# AI를 쓰면 성적이 오를까
생성형 AI 사용 습관이 대학생들의 성적에 어떤 영향을 주는지 알아보기

## 1) 팀원
- 20617 오지현
- 20814 윤승민

## 2) 우리 팀의 질문
### "생성형 AI를 많이 쓰는 학생일수록 성적이 더 오를까?"
- AI를 오래 사용할수록 대학생들의 평균 학점도 높아지는지 알아보기
- AI를 사용하는 시간뿐만 아니라, 정답만 얻는 방식과 함께 문제를 풀어가는 방식처럼 사용 방법에 따라 성적이 달라지는지 알아보기
- AI 사용 시간 외에도 AI 없이 직접 공부한 시간 등이 성적 변화와 어떤 관계가 있는지 알아보기

## 3) 데이터 선정 이유 – 질문에 적합한 변수 구성: 
- 성적 변화 분석 가능: 학생별 학기 전 GPA(Pre_Semester_GPA)와 학기 후 GPA(Post_Semester_GPA)가 모두 제공되어, 두 점수의 차이를 계산해 성적 변화 정도를 분석할 수 있다.
- 다양한 AI 사용 특성 비교 가능: 주당 AI 사용 시간뿐만 아니라 주요 사용 목적, 프롬프트 작성 능력, 사용 도구 수, 유료 구독 여부, AI 의존도 등의 변수가 있어 AI를 사용하는 시간과 방법을 함께 비교할 수 있다.
- 성적에 영향을 미치는 다양한 요인 분석 가능: AI 사용 시간 외에도 AI 없이 공부한 시간, 시험 불안, 학교의 AI 사용 정책, 전공 및 학년 등의 변수를 활용해 성적 변화와 관련된 요인을 분석할 수 있다.
- 대규모 데이터를 활용한 다양한 분석 가능: 총 5만 명의 학생과 16개의 변수로 구성되어 있으며 결측치가 없어, 성적 변화 예측을 위한 회귀분석과 성적 상승 여부를 구분하는 분류 분석 등 다양한 데이터 분석을 진행할 수 있다.
- 실생활과 관련된 주제: 생성형 AI는 현재 교육 환경에서 널리 활용되고 있는 기술이므로, 분석 결과를 통해 AI 사용 습관과 학업 성취도의 관계를 살펴보고 효과적인 학습 방법에 대해 논의할 수 있다.
