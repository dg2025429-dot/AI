# AI를 쓰면 성적이 오를까

## 팀원
### - 20617 오지현
- 20814 윤승민

대학생 5만 명의 학기 전·후 GPA와 생성형 AI 사용 습관 데이터로 알아보는 스트림릿 앱 실행: streamlit run code/main.py

1) 우리 팀의 질문

"생성형 AI를 많이 쓰는 학생일수록 성적이 더 오를까?"

AI를 오래 쓰면 GPA가 더 오르는지, 아니면 사용 시간과는 상관이 없는지
같은 시간을 써도 어떻게 쓰느냐(정답 받기 vs 함께 문제 풀기, 프롬프트 실력)에 따라 달라지는지
AI 사용 시간 외에 성적 변화와 더 관계 깊은 요인(예: AI 없이 공부한 시간)은 무엇인지
2) 데이터 선정 이유
질문에 딱 맞는 변수: 학생마다 학기 전 GPA(Pre_Semester_GPA)와 학기 후 GPA(Post_Semester_GPA)가 모두 있어서 '성적이 올랐는지'를 변화량으로 직접 계산할 수 있다.
AI 사용을 다양한 면으로 측정: 주당 사용 시간, 주된 사용 목적, 프롬프트 작성 실력, 사용 도구 수, 유료 구독, 의존도 등이 있어 '얼마나'뿐 아니라 '어떻게' 쓰는지도 비교할 수 있다.
비교할 다른 요인이 있음: AI 없이 공부한 시간, 시험 불안, 학교 정책, 전공·학년이 함께 있어 AI 외 요인과 견주어 볼 수 있다.
충분한 규모와 깔끔한 형태: 5만 명 × 16개 변수이고 결측치가 없어 집단별 비교가 안정적이며, 회귀(GPA 변화 예측)와 분류(성적 상승 여부, 번아웃 위험 등) 모두로 확장할 수 있다.
우리가 직접 겪는 주제: 같은 대학생의 이야기라 결과를 해석하고 토론하기 좋다
